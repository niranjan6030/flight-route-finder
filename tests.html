Test cases

These run in your browser every time this page is opened (it takes a few seconds). They call the same functions (js/routing.js) that the search page uses.

  • Tests 1 to 4 check the distance formula and the min-heap.
  • Tests 5 to 15 use a small network of 6 airports where I worked out the answers by hand. It is the worked example on the poster.
  • Tests 16 to 27 use the real network (3,257 airports, 37,042 routes). There I cannot know the answers by hand, so the methods are checked against each other and every route is checked to be a real one.
